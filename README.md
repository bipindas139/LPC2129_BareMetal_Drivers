# LPC2129 Bare-Metal Drivers

A collection of reusable register-level Embedded C drivers for the NXP LPC2129 ARM7TDMI microcontroller.

## Drivers

### MCU Drivers

- [x] UART0
- [ ] UART1
- [ ] GPIO
- [ ] TIMER
- [ ] VIC
- [ ] ADC
- [ ] DAC
- [ ] PWM
- [ ] SPI
- [ ] I2C
- [ ] RTC
- [ ] CAN

### Device Drivers

- [ ] ESP8266
- [ ] MAX30102
- [ ] LCD16x2
- [ ] EEPROM

## Design Goals

- Register-level programming
- No vendor libraries
- Bare-metal Embedded C
- Modular architecture
- Reusable drivers

## Toolchain

- MCU: NXP LPC2129
- Language: Embedded C
- Compiler: Keil MDK
