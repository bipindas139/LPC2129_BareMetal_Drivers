# UART0 Driver (LPC2129)

## Overview

Register-level UART0 driver developed for the NXP LPC2129 ARM7TDMI microcontroller.

## Features

- UART initialization
- Blocking transmit
- Blocking receive
- Receive with timeout
- String transmit
- String receive
- Integer printing
- Floating-point printing
- Hexadecimal printing

## Tested Baud Rates

- 9600
- 115200

## Files

- uart0.c
- uart0.h

## Future Improvements

- Interrupt-driven UART
- Circular receive buffer
- Configurable parity
- Configurable stop bits
